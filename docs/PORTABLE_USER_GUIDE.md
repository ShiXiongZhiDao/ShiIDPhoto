# 使用说明

## 这是什么

一个解压就能用的证件照工具。不用装 Python、不用配环境、不用下载模型，处理过程全部在你自己的电脑上完成。

## 三步

1. **解压**：把压缩包解压到任意有写入权限的文件夹（例如 `D:\证件照`）。不要在压缩包预览窗口里直接双击。
2. **双击** `启动师兄证照.bat`。
3. 浏览器会自动打开本地页面，把照片拖进中间那块区域即可。

首次启动分两种情况：

- **包里带模型**（自己用的完整包）：要加载并校验三个模型，大约 15–25 秒。
  黑色窗口会先显示「本地服务已响应」和地址，随后开始加载；浏览器会自动打开，
  页面上有转圈的「正在加载模型… 3s」，秒数在走就说明没卡死。

- **包里不带模型**（公开下载的瘦包）：页面会进入「首次使用」，列出缺的几个模型和体积。
  点「开始下载」即可，全程不用命令行。约 180 MB，网络正常时一分钟左右；
  可以暂停再继续，断线后会从断点接着下。装完自动进入主界面，不需要重开。
  下载不动时可以点「我有文件，手动安装」，选择已有的 `.onnx` 文件，
  程序会校验它是不是缺的那个模型。

如果超过 30 秒还没动静，看黑窗口里的提示，别直接关掉——关掉窗口就是关掉服务。

## 界面怎么用

左边是画布，右边是参数，底边是产出。

右边面板最上面那行「**怎么做**」就是操作顺序：`1 照片 2 规格 一寸 · 白 3 生成 4 下载`，
做完一步前移一格；它只占一行、不会消失、也没有开关——完整说明在「新手引导」里。
想跟着走一遍，点它右边那颗「**新手引导**」——屏幕会压暗、一次只点亮当前那个控件，
四步走完自动退出，中途按 `Esc`、点空白处或「跳过」都能立刻退出。被点亮的那个控件在引导里照常能点。
引导不记"看过没有"，随时可以再点。

1. **把照片拖进来**——拖到画布上，或点画布里的虚线框选文件，也支持 `Ctrl+O`。
   虚线框下面那两行是拍照要求（单人正面、头顶上方留空），放完照片它就消失，之后由画布上方的黄色提示接手；
2. **规格 · 底色**——打开页面时已经替你选好（默认一寸 · 白），要改就在下面点，不改就直接下一步；
3. **生成证件照**——右下角那颗按钮，或 `Ctrl+Enter`，几秒出结果；
4. **下载所选 / 打开文件夹**——前者走浏览器下载，后者直接打开 `user-data\output`。

步骤引导只讲"做哪一步"，不讲参数。参数层的说明：

- **选规格**：右侧「规格」里点一下就行。常用六种直接列出，其余的在「更多规格」下拉里。
- **选底色**：十个常用底色，点一下选中。
- **选输出**：默认停在「单张」，只要电子版；此时相纸下拉、排版行数与底部那张相纸缩略图**都不显示**，
  免得看着像还要管排版。要拿去冲印就点「相纸排版」，这三处原样回来，它还会额外拼一张相纸图。相纸尺寸和行列数会自动按规格算好（比如一寸铺满六寸是 4×4 共 16 张）。
- **看结果**：底部两个缩略图可以在「单张」和「相纸」之间切换；画布上的参考线和裁切标记可以用左下角开关关掉。
  如果画布上方出现一条黄色提示，说明这张图有风险（最常见的是没检测到人脸），先看提示再决定要不要用。

## 设置会记住

你选过的**规格、底色、输出模式、相纸、自定义尺寸**，加上格式、质量、体积上限，
存在包里的 `user-data\prefs.json`，下次打开还在——刷新页面、关掉重开、甚至换浏览器都一样，
因为它不跟浏览器走，跟包走。改动即存，不用点保存。

三件事要说明白：

- **`--preset` 启动参数赢**，而且那一次**不会**改掉你记住的设置（显式指令大于记忆）。
- **自定义尺寸只认"保存过的那条"**。临时填一个宽高直接生成、没点「保存」，重启后回到默认规格，
  界面会写清楚为什么回退。
- **某项失效时不静默**：上游规格表改了名、你删了那条自定义尺寸，按钮上方会常驻一行
  「上次选的『某某』找不到了，已回退」，一条一个原因。

清空照片、参考线与裁剪框开关**不记**——前者是本次的图，后者只改画布显示，不影响成片。

## 用哪张照片

- 单人、正面、五官清晰、光线均匀。
- **头顶上方要留出空间**。这是最容易踩的坑：如果原图里头发已经贴到画布上边缘，
  程序补不出白边，出来的一寸照头顶会紧贴边（只有 1mm 左右），拿去提交容易被退回。
  拍的时候头顶上方留出约一个额头的空，或者干脆用原图（别先裁到只剩脸）。
- 手机拍的也行，但别用美颜滤镜拍的原图——滤镜会干扰人脸检测。
- 复杂背景、多人合影、侧脸、遮挡，效果会明显变差。这是工具本身的边界，不是故障。

## 选规格

打开页面时，**规格和底色已经替你选好了**：默认是一寸 · 白底 · **单张电子版**，
丢进照片直接点生成就行。相纸仍记着六寸——切到「相纸排版」时不用重选，直接排 4×4 共 16 张。

要换规格，改「照片类型」和「预设颜色」两个下拉框即可。常用组合已经内置为预设：

| 预设 id | 界面显示 | 适用 |
|---|---|---|
| `one-inch-white` | 一寸 · 白底 · 六寸 16 张 | 报名表、社保卡、各类考试，最通用 |
| `one-inch-blue` | 一寸 · 蓝底 · 六寸 16 张 | 单位档案、学生证 |
| `two-inch-blue` | 二寸 · 蓝底 · 五寸 4 张 | 毕业证、学位证、职称证书 |
| `small-two-inch-white` | 小二寸 · 白底 · 六寸 9 张 | 护照、港澳通行证、部分签证 |
| `id-card-white` | 中国居民身份证 · 白底 | 358×441 @350dpi，只要电子版 |
| `visa-us-white` | 美国签证 · 白底 | 600×600 正方形 |
| `driver-license-white` | 中国驾驶证 · 白底 · 六寸 16 张 | 车管所提交 |

想默认停在别的预设上，用启动参数指定（bat 支持透传）：

```bat
启动师兄证照.bat --preset two-inch-blue
```

也可以改 `config\presets.json` 里的 `defaults.id` 长期生效，不必重新构建，改完重启即可。
id 写错时不会静默忽略：启动窗口会打印「预设「xxx」不存在，回退到「…」」，页面停在默认预设上。

其余参数保持默认就好。**不要随手改「人脸占比」和「顶部留白」**——默认值是配合证件照构图调过的，
改小了会变成大头照，改大了会变成证件半身像。

## 自定义尺寸

内置 34 个规格之外，还能自己填。点规格网格末尾的「**+ 自定义**」：

- **像素**：直接填宽 × 高，比如报名系统给的 `358×441`。
- **毫米**：填物理尺寸和 DPI，比如 `33×48mm @300dpi`，页面会实时算出像素
  （33×48mm @300dpi = 390×567 px）。像素和毫米**二选一**，切换时自动换算，
  不会同时生效。

名字可不填，不填就用尺寸当名字（如「33×48mm」）。要给常用规格起名（比如
「某省考报名」），存 20 条以内，保存在 `user-data\custom-sizes.json`，
升级重装不会丢；点列表里的一条可以直接再次使用，右边的 × 删除。

填好点「用这个尺寸」，规格网格最后一张卡片会显示你的数值，排版行会自动算出
这张相纸能排几张。相纸放不下这个尺寸时（自定义尺寸比整张相纸还大），排版行
会直接写「放不下 · 请改用单张」，不用点了生成才知道。

**两个要知道的事**：

1. 裁切比例按**通用证件照**处理（脸占高度约 30%）。护照、签证等要求
   「脸占更大」的类别，这里做不出来——请去受理单位指定的渠道拍。
2. 自定义规格**不能设为默认预设**，每次打开要先点一下自定义卡片。
   预设只认内置规格，这是构建期校验的一部分。

## 结果在哪

- 处理结果：`user-data\output\`（界面上的「保存目录」也指向这里）
- 运行日志：`user-data\logs\webui.log`

## 输出格式与体积

右侧「输出」里有三项：**格式**、**质量**、**体积**。

### 格式

默认 JPG，单张和相纸使用同一个格式，下载的文件名也跟着变。

- **JPG**：最通用，报名系统基本都认。
- **JPEG**：和 JPG 是同一个编码器，只是扩展名不同。有些系统明确要求 `.jpeg` 时选它。
- **PNG**：无损，文件更大；需要避免二次压缩、或平台要求 PNG 时用。

不提供 WebP：保存时拿不到 300dpi 元数据，打印尺寸会不对。

### 质量

| 档位 | 数值 | 适用 |
|---|---|---|
| 高 | 92 | **默认**。打印、存档，画质优先 |
| 标准 | 75 | 与 2026-11 之前的版本一致，体积小三分之一 |
| 较小 | 60 | 上传受限、肉眼看不出明显差别 |
| 最小 | 45 | 只要能过审，画质让位 |

单张一寸照在这四档下大约是 39 / 23 / 18 / 14 KB。相纸因为面积大，约是单张的 8–9 倍。

**默认是最高质量，所以默认的输出比以前大**。如果报名系统卡 30 KB、50 KB，
不用降档，直接勾下面的「体积上限」——程序会从 92 往下找，能装下就不降质。

### 体积上限

勾选「不超过」并填一个 KB 数（20–8192），程序会自动找你给的质量以下、
**能装进这个上限的最高质量**。不用自己反复试。

- 达标：按上限输出，缩略图上直接写实际体积。
- 压不到：告诉你最低能到多少，不会偷偷给你一个超标的文件。
- 压到了但质量低于 40：提示「画质可能不合格」——达标不等于能用，打印前请自己看一眼。

**PNG 不支持体积上限**：PNG 是无损格式，能调的只有压缩级别，压不动几 MB 的图。
选了 PNG 时质量与体积两项会直接变成一句说明，而不是给两个点了没反应的控件。

## 停止

关掉黑色的命令行窗口，或在窗口里按 `Ctrl+C`。

## 常见问题

**提示模型缺失或校验失败**
完整包出现这个提示，说明压缩包没解压完整，或者解压过程中被杀毒软件截断。重新解压一次。
瘦包没有模型是正常的——页面会引导下载，不需要手动找文件。

**模型下载失败 / 一直停在 0%**
先点「暂停」再点「继续下载」，会从断点重试；也可以关掉窗口重开，已下载的部分不会白费。
公司网络或代理拦截时，换一个网络，或点「我有文件，手动安装」选择已下载的 `.onnx` 文件。
程序不会在后台偷偷下载，也不会因此判定「模型损坏」。

**提示目录不可写**
把整个文件夹移到你有权限的位置，比如 `D:\` 或桌面。放在 `C:\Program Files` 下会失败。

**出图了，但画布上方提示「没有检测到人脸」**
程序没找到正脸，退而按画面里的主体或整张原图裁的，出来的图大概率不符合证件照要求。
换一张单人、正面、五官清楚的照片重试。这类图仍会正常保存，但请自己确认再拿去用。

**端口被占用**
程序会自动换端口，并在窗口里显示实际地址。以窗口显示的为准，不要死守 7860。

**页面打不开**
先看 `user-data\logs\webui.log` 的最后几行。常见原因是杀毒软件拦截了本地端口。

**提示缺少 VCRUNTIME140.dll**
装一下微软官方的 [Visual C++ Redistributable](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist)。
这是 Windows 通用运行库，与本工具无关，很多软件都需要。

**压缩功能不可用**
`pngquant` 因许可证原因没有随包提供。需要的话自己下载后放到 `src\tool\ext\pngquant.exe`。
不放也不影响出片，只是输出体积大一点。

## 已知限制

- 自动美肤未包含在本版本中（模型许可未核实），界面上的相关选项不会生效。
- 仅承诺 Windows 10/11 x64。Windows 7 可能出现运行库问题。
- 只监听 `127.0.0.1`，同一局域网的其它设备访问不到，这是有意的。

## 关于证件照合规

各地各机构的规格要求会变，工具只负责按你选的规格出图。提交前请自己核对受理单位的最新要求，
尤其是头部比例、是否允许戴眼镜、背景色深浅这类细节。
